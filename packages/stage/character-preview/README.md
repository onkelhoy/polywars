# @polywar/character-preview

Character viewer: pw-3d-asset-preview with the skeleton (IK) and Blender style bones, mesh / bones / in front / IK toggles.

## installation

```bash
npm install @polywar/character-preview
```

### to use in **html**

```html
<script type="module" defer>
  import "@polywar/character-preview";
</script>

<pw-character-preview></pw-character-preview>
```
